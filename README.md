# TypePulse Pro - Keyboard Precision & Reflex Arena

**TypePulse Pro** is a modern touch-typing mastery and letter recognition arena built with vanilla HTML5, CSS3, and JavaScript, powered by the Web Audio API for procedural sound effects.

## 🎮 Game Modes

### Mode A: Bubbles (Letter Recognition)
- Floating letter bubbles rise toward a critical escape ceiling.
- Pop bubbles by pressing the matching key on your keyboard before they hit the boundary.
- Dynamic speed escalation as your score increases.
- Penalty for incorrect strikes (-5 pts) and miss limit.
- **Goal:** Clear target bubbles (30 Easy, 45 Medium, 60 Hard) to achieve Victory!

### Mode B: KeyMagnet (Keyboard Precision)
- Interactive tactile on-screen keyboard with magnetic target illumination.
- Practice sets: Home Row, Top Row, Bottom Row, Full Alphabet, and Numbers.
- Millisecond reaction latency tracking and speed bonus points.
- Strict reaction window per key (2.6s Easy, 1.6s Medium, 1.0s Hard).
- **Goal:** Clear all targets in the sequence within allowed strikes!

## ⚡ Features
- **Difficulty Levels:** Easy, Medium, and Hard with distinct speed, target complexity, and sequence limits.
- **Real-Time HUD:** Live score, streak multiplier, lives/misses, correct & error keypress counts, and countdown timer.
- **Immediate Feedback:** Crisp particle bursts, screen shake, tactile key lighting, and procedural synthesizer audio.
- **Results Modal:** Performance grade (S, A, B, C, D), accuracy percentage, latency breakdown, and actionable verdicts.
- **Zero-Reload Controls:** Seamless Start, Pause, Restart, and Reset without page refreshing.
- **Responsive Design:** Fully responsive layout with mobile touch support for both bubbles and virtual keys.
